# CELEBRA — Assets Repository

Esta carpeta contiene los recursos multimedia de la plataforma **CELEBRA — INVITACIONES DIGITALES**:

- `/logo`: Logotipos oficiales en alta definición (SVG vectorial, favicon e isotipos con la doble C estilizada y estrellas).
- `/music`: Pistas de audio para ambientación de invitaciones y efectos sonoros de interacción (check-in, fanfarria).
- `/video`: Clips de video de fondo, intros y animaciones de confeti.
- `/images`: Portadas de eventos, fondos temáticos para plantillas (Bodas, XV Años, Gala, Neón, etc.).
