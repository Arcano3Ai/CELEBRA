# 📁 CARPETA DE FOTOS Y RECURSOS DEL STAFF — CELEBRA & DIVERTIFIESTA

Esta carpeta está destinada a almacenar las fotografías, avatares y credenciales de los miembros del **Staff de Eventos** (Control de Acceso QR, Recepción, Animadores, Artistas y Coordinación).

---

## 📸 Nombres de Archivo Recomendados:
- `staff-recepcion-1.jpg` / `.png`: Fotografía del personal de recepción y bienvenida.
- `staff-checkin-puerta.jpg` / `.png`: Operador de escáner QR en puerta principal.
- `staff-coordinador.jpg` / `.png`: Coordinador de logística y tiempos del evento.
- `staff-animador-show.jpg` / `.png`: Animador, maestro de ceremonia o artista de show.
- `staff-seguridad.jpg` / `.png`: Personal de control de aforo y seguridad.

## 📐 Especificaciones de Imagen:
- **Relación de aspecto:** 1:1 (cuadrado) para avatares o 3:4 (retrato vertical) para credenciales.
- **Resolución sugerida:** 600x600 px o 800x1060 px.
- **Formatos admitidos:** JPG, PNG, WEBP, SVG.
- **Peso máximo recomendado:** < 400 KB por imagen para carga ultrarrápida.
