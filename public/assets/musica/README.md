# CARPETA DE MÚSICA Y AUDIO CELEBRA

Aquí se almacenan las pistas de audio para las invitaciones digitales y efectos sonoros:
- Pistas de música ambiental en formato MP3 o WAV (ejemplo: Vals de gala, lounge cóctel, fiesta).
- Efectos de sonido (check-in exitoso, fanfarria).
- La aplicación reproduce por defecto `celebration-melody.wav`.
